# Local brand glyphs

Logos that neither simple-icons nor Lobe ship, drawn here and read by `scripts/brand-icons.mjs` (set `local`).
Each file is a single `<svg>` with a `<title>` and plain `<path>` elements, drawn in black or `currentColor`.

- `e2b.svg`: a plain "E2B" wordmark, not E2B's own logo. E2B is a trademark of its owner; the glyph only names the
  sandbox provider a coding agent runs in.
